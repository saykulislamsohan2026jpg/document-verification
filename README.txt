MINIMAL DOCUMENT VERIFIER TEMPLATE

Open index.html in a browser to preview.

To edit:
1. Open index.html in a text/code editor (for example, VS Code).
2. Find the const SITE = { ... } section near the bottom.
3. Change the sample text, website URL, email, phone numbers, address, table headers and rows.
4. To add table rows, add another array inside rows, e.g.
   ["Transcript", "TR-002", "Education", "Available"]
5. For the Visit Website button, set visitWebsite to your destination URL.
6. For email, set email to your address. It opens an email compose action with mailto:.
7. For click-to-call, set hotlineNumber/contactNumber with country code, e.g. +8801XXXXXXXXX.
8. For a background photo, set backgroundImage to a publicly accessible image URL. Leave "" for the plain pale-green background.
9. Save and upload index.html to a static website host such as GitHub Pages. Rename nothing: keep it as index.html.

This is a neutral personal template, not an official bank/government website or a financial statement validation service. Do not use another institution's logo, name, or claims of verification. Use only information you are authorized to publish.
